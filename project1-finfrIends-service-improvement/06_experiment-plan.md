# 실험 설계서

> **검증 단계** MVP 프로토타입 검증(Validation) — 규모가 아니라 **인과 주장**을 확인하는 단계
> **검증 우선순위** 가장 먼저 깨질 수 있는 가정부터. **E1이 무너지면 서비스 전제 전체가 무너지므로 최우선**

| 순위 | 실험 | 검증하는 것 | 무너지면 잃는 것 |
|---|---|---|---|
| 1 | **E1** | 소멸성 용돈보다 '가시적 성장'이 동기로 작동하는가 | **서비스 전제** |
| 2 | **E2** | 성장 루프가 실제 '학습'을 유발하는가 | 정체성 (퍼핀이 실패한 지점) |
| 3 | **E3** | 나무 UI 성장 시각화가 부모 '확신감'으로 이어지는가 | 수익모델 전제 |
| 4 | **E4** | 온보딩에서 첫 성장 경험까지 무개입 도달하는가 | NSM 분모 확보 |

> ⚠️ **성공 기준의 수치는 확정 목표치가 아니라 가설적 기준(초기 가정치)입니다.** 벤치마크가 없는 신규 경험이라 팀이 설정한 값이며, 1차 테스트 실측값으로 캘리브레이션한 뒤 확정합니다. **숫자의 절대 달성보다 A군 대비 B군의 방향성이 먼저입니다.**

## E1 — [아이 / 최우선] 소멸성 용돈보다 '가시적 성장'이 동기로 작동하는가

| 항목 | 내용 |
|---|---|
| **대상** | 아이 7~14세, A군 8~10명 / B군 8~10명 (총 16~20명) · 퍼핀 또는 유사 용돈앱 사용 경험자 우선 |
| **가설** | 보상을 캐릭터 성장으로 주면, 아이는 용돈 보상 못지않게(또는 그 이상) **자발적으로 학습을 지속한다** |
| **방식** | 프로토타입 A/B — **A: 용돈 보상형(퍼핀식)** / **B: 캐릭터 성장 보상형**. 1~2주 사용 + 행동 로그 수집 |
| **필요한 데이터** | `app_open`(속성: 용돈 잔액), `lesson_start`/`lesson_complete`, `quiz_answer`, `star_earn`, `item_unlock`, `item_equip`, 주차별 세션 로그 |
| **성공 기준** | ① **B군 학습 지속률 ≥ A군** (W2 기준) ② **B군 자발적 재방문율 ≥ 40%** (용돈 잔액이 있는 상태의 학습 방문) |
| **결과 판정** | 두 기준 모두 충족 → 진행 / ①만 충족 → 보완 후 재측정 / ① 미충족 → 전제 재검토 |
| **실패 시 학습** | 성장 보상이 용돈의 동기 강도를 대체하지 못함 → ① **'성장을 남긴다' 컨셉 자체 문제**인지 ② **성장 보상의 매력(옷 다양성·희소성) 문제**인지 분리 재검증. 후자면 **보상 이원화(용돈 + 성장 병행)로 피벗** |

---

## E2 — [아이] 성장 루프가 실제 '학습'을 유발하는가 *(퍼핀이 실패한 지점)*

| 항목 | 내용 |
|---|---|
| **대상** | E1의 **B군 8~10명** (별도 리크루팅 불필요) |
| **가설** | 성장이 목표가 되면 아이는 보상만 노리지 않고 **자료·해설을 읽고 이해하려 한다** |
| **방식** | 사용성 테스트 + 행동 로그. 정답 여부·해설 행동을 **화면 관찰**과 로그로 이중 확인 |
| **필요한 데이터** | `quiz_answer`(정답 여부·풀이 시간), `quiz_explain_view`(열람 시간), `lesson_complete`(스크롤 도달률·체류 시간), 오답 후 재도전 로그 |
| **성공 기준** | **해설 열람률 ≥ 60%** *(퍼핀 리뷰 E-05 "해설도 제대로 보지 않습니다"의 반증선)* · 보조: 오답 후 재도전율 ≥ 40% |
| **결과 판정** | 해설 열람률이 반증선을 넘으면 → 학습 행동이 실제로 발생 / 미달 시 → 보상 경로 재설계 |
| **실패 시 학습** | 성장 보상이 학습의 '질'까지는 못 끌어올림 → **별 획득 조건을 '정답'이 아니라 '해설 열람 + 이해 확인 문항'에 연동**해 학습 행동을 보상 경로에 강제 편입 |

---

## E3 — [부모] 나무 UI 성장 시각화가 '확신감'으로 이어지는가

| 항목 | 내용 |
|---|---|
| **대상** | 초등 자녀를 둔 부모 8~10명 (용돈앱 사용 경험자) |
| **가설** | 학습 성장을 나무 UI로 가시화하면 부모는 **'습관으로 자리잡는다'는 확신**을 느껴 서비스를 유지한다 |
| **방식** | 부모 프로토타입 테스트 + **사전/사후 확신감 설문** + 조회 빈도 로그 |
| **필요한 데이터** | `learning_status_view`(체류 시간), `learning_answer_check`(문항 수), 사전/사후 설문 응답, 구독 유지의향 응답 |
| **성공 기준** | ① **습관화 인식 동의율 ≥ 70%** ② **주 1회+ 조회율 ≥ 50%** ③ **구독 유지의향 ≥ 60%** |
| **결과 판정** | 3개 중 2개 이상 충족 → 진행 / ①만 충족 → 전달 방식 보완 / ① 미충족 → 수익모델 재검토 |
| **실패 시 학습** | 나무 UI만으로는 확신 근거가 부족 → 부모가 확신을 얻는 **진짜 단서(정답률/진도/실생활 적용)를 인터뷰로 규명**한 뒤, **주간 리포트 푸시 등 능동 전달형**으로 전환 |

---

## E4 — [진입] 온보딩에서 첫 성장 경험까지 무개입 도달하는가

| 항목 | 내용 |
|---|---|
| **대상** | **E1 참가자의 첫 세션**에서 병행 측정 (별도 리크루팅 불필요) |
| **가설** | 가입 첫 세션 안에 「아바타 생성 → 첫 퀴즈 → 별 획득 → 아바타 변화」를 완주하면 아이는 앱의 가치를 이해한다 *(퍼핀: 카드 도착 전 "할 게 없어서" 이탈의 반대 설계)* |
| **방식** | 온보딩 플로우 관찰 — **개입 없이 완주하는지** 관찰하고 막히는 화면을 기록 |
| **필요한 데이터** | `avatar_create_complete`(사진 사용 여부·소요 시간), 첫 `quiz_answer`, 첫 `star_earn`, 첫 `item_unlock`, 단계별 이탈 지점, 완주 소요 시간 |
| **성공 기준** | **5분 이내 무개입 완주 70% 이상** |
| **결과 판정** | 70% 이상 → NSM 분모 신뢰 가능 / 미달 → **이 지표가 낮으면 NSM(지속률)이 높아도 신뢰 불가**(분모 편향)이므로 최우선 수정 |
| **실패 시 학습** | 이탈 지점이 **사진 촬영**이면 → 기본 아바타로 시작하는 스킵 경로 강화(사진은 선택사항). **퀴즈**에서 막히면 → 온보딩 전용 쉬운 문항으로 교체 |

## 실행 일정 (안)

| 주차 | 활동 |
|---|---|
| **W1** | 프로토타입 완성 · **E4** 온보딩 테스트 |
| **W2~3** | **E1** A/B (아이 16~20명) · **E2** 병행 관찰 |
| **W3** | **E3** 부모 테스트 (8~10명) + 사전/사후 설문 |
| **W4** | 판정 — 지속 / 보완 / 피벗(보상 이원화) 결정 |

## 공통 운영 원칙

- **참여 동의** 만 14세 미만 아동 참여이므로 **법정대리인 동의**를 사전 확보하고, 아동에게도 구두로 참여 의사를 확인한다.
- **로그 최소 수집** 실험 판정에 필요한 이벤트만 수집하고, 종료 후 개인 식별 가능 데이터는 파기한다.
- **관찰자 개입 금지** E4는 무개입 완주율이 지표이므로, 진행자는 아이가 요청하기 전까지 개입하지 않는다.
