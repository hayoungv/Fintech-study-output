아이 4탭 × 부모 4탭 — 각자의 역할에 맞는 화면

핀프렌즈는 두 개의 재화로 돌아갑니다. 아이는 학습해서 별⭐을 모아 아바타를 키우고, 미션을 수행해서 저금통🐷에 실제 용돈을 담습니다. 이 문서는 그 두 루프가 어떤 화면을 거쳐 도는지를 순서대로 보여줍니다.

초록 = 아이 앱학습·성장에 관한 모든 것
파랑 = 부모 앱확인·승인·관리에 관한 모든 것
노랑 = 재화별⭐ · 저금통🐷 (돈이 걸린 것)
화면 읽는 법회색 상자 = 실데이터 · 점선 = 이미지/미디어 · C1은 아이, P1은 부모 화면 번호

화면별 상세

각 화면 설명은 목적 → 구성 요소 → 연결 순서로 고정되어 있습니다.

🧒 아이 앱

4탭 + 서브 5화면

가치: “금융 활동 목표 달성으로 느끼는 성취감” — 보상이 쓰면 사라지는 용돈이 아니라 눈에 보이는 성장으로 남는다.

1

홈 ⭐ 학습 루프의 결과가 보이는 곳

모은 별이 실제 변화로 바뀌는 것을 확인하는 탭. 앱을 열면 자동으로 출석이 처리됩니다.

C1 홈 → C2 옷장

2

별모으기 ⭐ 학습 루프 본체

별을 얻는 유일한 경로. 퀴즈 앞에 반드시 학습 단계를 두어 “찍어서 보상만 받는” 흐름을 막습니다.

C3 커리큘럼 → C4 학습 → C5 퀴즈 · 별도 C6 출석

3

내통장 🐷 미션 루프의 결과

별이 아니라 실제 돈을 다루는 탭. 부모 P1과 같은 데이터를 아이 시점으로 보여줍니다.

C7 내통장 · 같은 데이터의 부모 화면 P1

4

미션 🐷 미션 루프 · 아이 구간

부모가 등록한 미션을 수행하고 사진으로 증명해 제출하는 탭. 돈은 승인 이후에만 들어옵니다.

P5 부모 등록 → C8 미션 선택 → C9 인증 제출 → P4 부모 승인

👨‍👩‍👧 부모 앱

4탭 + 서브 2화면

가치: “아이의 금융 학습이 습관으로 자리잡고 있다는 확신감” — 노는 것 같은데 학습이 계속된다.

1

아이통장 🐷 돈이 보이는 홈

부모가 앱을 열면 가장 먼저 보는 화면. 아이 돈의 유입·유출을 한눈에 보고 바로 송금합니다.

P1 아이통장 · 아이 쪽 같은 화면 C7

2

학습 현황 ⭐ 학습 루프를 부모가 보는 창

아이가 별을 모으는 동안 실제로 무엇을 배웠는지를 나무 성장 UI와 답안으로 확인합니다.

C5 퀴즈 결과 → P2 학습 현황

3

미션 관리 🐷 미션 루프 · 부모 구간

용돈을 “그냥 주는 돈”이 아니라 수행의 대가로 설계하고, 인증 사진을 확인해 지급을 결정합니다.

P3 관리 → P5 생성 · 아이 제출 시 P4 승인

4

마이페이지

계정·계좌·가족 연결과 앱 설정. 자녀 추가 연동도 여기서 시작합니다.

P6 마이페이지 · 가족 등록 → 자녀 초대(QR) 온보딩
