# 현재 사용자 플로우 분석 (AS-IS)

> **대상 서비스** 퍼핀(firfin) — 레몬트리 운영, 자녀 용돈관리·경제교육 앱
> **분석 범위** 서비스 전체가 아니라 **'퍼핀월드 학습·보상' 기능 하나**로 좁힘
> **분석 방법** 팀원 3인이 실제 가입·사용하며 화면 캡처 + 외부 사용 후기 블로그 교차 확인 (2026-08)
> **표기** 🟥 이탈 지점 · 🟨 마찰 지점 · ✅ 완료 조건

---

## 1. 아이 — 학습·보상 플로우 (핵심 분석 대상)

**목표 행동** 퍼핀월드에서 금융 퀴즈를 풀고 보상을 받는다
**완료 조건** 하루 5문제를 소진하고 퍼핀머니가 잔액에 적립된다

| # | 화면 | 사용자 행동 | 시스템 반응 | 상태 |
|---|---|---|---|---|
| **A1** | 아이 홈(지갑) | 앱 실행 | 잔액·최근 내역 표시 | 진입 |
| **A2** | 퍼핀월드 | 메타버스 맵에서 퀴즈 지점 선택 | 퀴즈 진입 | 진행 |
| **A3** | 퀴즈 출제 | 문제 확인 | **하루 5문제 제한** · 제휴사 콜라보 퀴즈 혼재 | 🟨 마찰 1 |
| **A4** | 보기 선택 | 정답/오답 선택 | 즉시 정오 판정 · 해설 노출(열람은 선택) | 🟨 마찰 2 |
| **A5** | 보상 지급 | — | 부모가 설정한 금액 적립 · **오답 시 절반 지급** | 🟨 마찰 3 |
| **A6** | 퍼핀월드 학습현황 | 결과 확인 | 시작한 지 116일 / 해결 문제 75개 / 누적 보상 6,650원 | 🟨 마찰 4 |
| **A7** | — | 5문제 소진 | 당일 종료 | ✅ 완료 |

### 마찰 지점 상세

| 지점 | 무엇이 마찰인가 | 사용자에게 생기는 손실 | 근거 ID |
|---|---|---|---|
| **🟨 A3** | 금융 커리큘럼이 아니라 제휴 마케팅·구독 판촉 퀴즈가 섞여 출제됨 | 부모가 "체계화된 금융 학습"으로 인식하지 못함 | E-03, E-04 |
| **🟨 A4** | 해설 열람이 보상 조건이 아님 — 읽지 않아도 다음으로 넘어감 | 학습(읽기·이해)이 일어나지 않음 | E-05 |
| **🟨 A5** | **오답에도 보상의 절반이 지급**됨 (앱 안내 문구에 명시) | "찍어도 돈이 나온다" — 문제를 제대로 읽을 유인이 사라짐 | E-05, E-08 |
| **🟨 A6** | 결과가 **누적 숫자 3개**뿐 — 무엇을 배웠는지·진도·내 답안이 없음 | 아이는 성장감 없음, 부모는 학습 여부 확인 불가 | E-01, E-05 |

> **구조적 결론** 보상이 **쓰면 사라지는 현금** 한 종류뿐이라, 루프를 돌아도 학습의 흔적이 남지 않는다.
> `퀴즈 정답 → 현금 보상 → 소비 → 흔적 없음 → 학습 동기 소멸`

## 2. 부모 — 학습보상 설정 플로우

**목표 행동** 자녀의 학습을 관리·확인한다
**완료 조건** 퀴즈 1문제당 보상 금액을 저장한다

| # | 화면 | 사용자 행동 | 시스템 반응 | 상태 |
|---|---|---|---|---|
| **B1** | 부모 홈 | '용돈계약' 진입 | 계약 항목 목록 | 진입 |
| **B2** | 퍼핀월드 학습보상 | "퀴즈 1문제에 얼마를 줄까요?" 확인 | 안내 3줄 노출 (하루 5문제 / 오답 시 절반) | 진행 |
| **B3** | 보상 금액 선택 | 20 · 60 · 100 · 200 · 400 · 600 · 800 · 1,000원 중 선택 | 금액 저장 | 🟨 마찰 5 |
| **B4** | 저장 | 적용 | 아이 화면에 즉시 반영 | ✅ 완료 |
| **B5** | 메인 · 아이 학습현황 | 결과 확인 | 누적 숫자 3개만 표시 | 🟨 마찰 6 |

### 마찰 지점 상세

| 지점 | 무엇이 마찰인가 | 사용자에게 생기는 손실 | 근거 ID |
|---|---|---|---|
| **🟨 B3** | 부모가 조절할 수 있는 변수가 **금액 하나**뿐 — 무엇을·어떤 순서로 배울지는 선택지에 없음 | 학습 설계 권한이 없어 '교육 서비스'로 신뢰하기 어려움 | E-01, E-02 |
| **🟨 B5** | 확인 가능한 결과가 누적일·문제 수·누적 보상액뿐 | **"아이가 지금 무엇을 알고, 무엇을 모르나"에 답을 얻지 못함** | E-01, E-05 |

> **구조적 결론** 부모의 개입 지점이 **보상 금액 설정 1곳**이라, 학습 품질에 관여할 수단이 없다.
> 부모가 보상을 걸지 않으면 아이의 학습 루프 자체가 멈춘다(동기의 외주화).

## 4. 개선 대상 확정

| 구분 | 내용 |
|---|---|
| **대상 사용자** | 아이 7~14세 × 부모(법정대리인) |
| **사용 상황** | 아이가 하루 1회 앱을 열어 금융 퀴즈를 푸는 순간 / 부모가 주 1회 학습 결과를 확인하는 순간 |
| **좁힌 기능** | 퍼핀월드 **학습·보상 루프** (A2~A6, B2~B5) |
| **건드리지 않을 것** | 송금·잔액 조회·이상거래 알림 등 **퍼핀이 이미 잘하는 용돈관리 기능** |
| **목표 행동(TO-BE)** | 아이: 학습→퀴즈→해설까지 완주해 별을 얻는다 / 부모: 진도·정답률·아이의 답안을 확인한다 |
| **완료 조건(TO-BE)** | 아이: 별로 옷을 잠금해제해 캐릭터가 변한다 / 부모: 나무 성장 UI로 학습 누적을 확인한다 |

> 근거 ID는 `02_페인포인트_근거표.md` 참조.
