# KPI Tree

> **고객 가치** 아이 — "금융 활동 목표 달성으로 느끼는 **성취감**" / 부모 — "아이의 금융 학습이 습관으로 자리잡고 있다는 **확신감**"
> **서비스 정체성(MVP Solution)** 아이의 금융 학습 과정에서의 **단계적이고 가시적인 성장감**

## 2. North Star Metric

| 항목 | 내용 |
|---|---|
| **지표명** | 주간 성장 지속률 (Weekly Growth Retention) |
| **정의** | 직전 주에 캐릭터 성장(별 획득 + 아바타 변화)을 경험한 아이 중, 다음 주에도 학습을 이어간 비율 |
| **계산식** | `(직전 주 성장 경험 아이 중 이번 주 lesson_complete ≥ 1) ÷ (직전 주 성장 경험 아이)` |
| **왜 이 지표인가** | 아이 '성취감'의 **결과**이자, 부모 '확신감(습관화)'의 **선행지표** — 두 고객 가치가 만나는 유일한 지점 |
| **왜 비율(rate)인가** | 지금은 **검증(Validation) 단계**. 규모가 아니라 "가시적 성장이 학습을 습관으로 만든다"는 **인과 주장 자체**를 측정해야 하고, 소수 테스터(8~10명)로도 측정 가능해야 함. E1 실험의 성공 기준(학습 지속률)과 NSM이 일치해 검증 논리가 한 줄로 이어짐 |

## 3. Input Metric — 개선 행동과의 인과 연결

> 각 지표는 **어떤 개선 행동이 움직이는 숫자인지**가 1:1로 정의되어 있습니다.

### 진입 (NSM의 분모를 만드는 선행 조건)

| 지표 | 정의 | 이 지표를 움직이는 개선 행동 | 인과 |
|---|---|---|---|
| **첫 성장 경험 도달률** | 가입 아이 중 첫 루프(학습→퀴즈→별 획득→아바타 변화)를 완주한 비율 | 온보딩 안에 **아바타 생성 + 첫 퀴즈 + 별 획득**을 강제 배치 (AS-IS 이탈 C4의 반대 설계) | 첫 세션이 완결되면 → 앱의 가치를 이해 → NSM 분모에 진입. **이 값이 낮으면 지속률이 높아도 신뢰 불가**(분모 편향) |

### 아이 · 성취감

| 지표 | 정의 | 이 지표를 움직이는 개선 행동 | 인과 |
|---|---|---|---|
| **학습 완주율** | 학습자료 열람 → 퀴즈 제출까지 도달한 세션 비율 | **퀴즈 앞에 학습 단계를 고정 배치** (C3 커리큘럼 → C4 학습 → C5 퀴즈, 건너뛰기 불가) | 순서를 강제하면 → 개념 이해 후 응답 → 완주율 상승 |
| **성장 소비율** | 획득한 별 대비 옷 잠금해제·착용에 쓴 비율 | **별 → 옷장 잠금해제 → 캐릭터 변화** 루프 제공 | 별이 실제 변화로 바뀌어야 → "내가 자랐다"가 체감됨. **성장 체감의 핵심 지표** |
| **자발적 재방문율** | 용돈 잔액이 있어도 돌아와 학습한 비율 | 보상을 **현금이 아닌 별**로 전환 (동기를 아이 안으로 이동) | 보상이 부모 지갑에서 분리되면 → 부모 개입 없이도 학습 지속 |
| **[반증] 해설 스킵률** | 퀴즈 제출 대비 해설 미열람 비율 | 문항마다 해설을 붙이고 **해설 뒤에 별 적립** | AS-IS 페인포인트(E-05 "해설도 제대로 보지 않습니다")의 **재현 여부 감시** |
| **[반증] 오답후 이탈률** | 오답 직후 세션을 종료한 비율 | 오답에 보상을 주지 않고 **재도전 경로** 제공 | 퍼핀식 '보상만 소비' 패턴이 우리 설계에서 재현되는지 확인 |

### 부모 · 확신감

| 지표 | 정의 | 이 지표를 움직이는 개선 행동 | 인과 |
|---|---|---|---|
| **성장 가시성 조회율** | 부모가 학습현황(나무 UI)을 확인한 빈도 (주 1회+ 조회 부모 비율) | 누적 숫자 3개 대신 **나무 성장 UI + 진도·정답률·아이의 답안·출석률** 제공 | 볼 것이 생겨야 → 열어본다. 확신감의 **행동 증거** |
| **습관화 인식 점수** | "우리 아이 금융학습이 습관이 되고 있다" 동의율 (설문) | 위와 동일 + 광고성 제휴 퀴즈 제거, 4주제 커리큘럼(벌기·쓰기·모으기·불리기) 고정 | 커리큘럼이 보이면 → '교육'으로 인식 → 습관화 확신 |
| **가치 유지율** | 주차별 리텐션 / 구독 유지율 | 구독의 근거를 '퀴즈 개수 해금'이 아니라 **부모용 인사이트**에 부착 (E-06 반대 설계) | 확신감이 유지되면 → 구독 유지. **수익모델의 종속 변수** |
| **추천의향 NPS** | "핀프렌즈를 다른 학부모에게 추천할 의향" 0~10점 | 위 3개의 종합 결과 | 옹호 강도 — 9~10 추천자 / 7~8 중립 / 0~6 비추천자 |

## 4. Guardrail Metric — 잘 될수록 감시할 것

| 지표 | 지키려는 것 | 기준 | 위반 시 조치 |
|---|---|---|---|
| **퀴즈 정답률 밴드** | 난이도 밸런싱 — 너무 쉬우면 별 인플레, 어려우면 이탈 | **60~85% 유지** | 문항 난이도 재배치 |
| **별 미사용 적체율** | 별이 쌓이기만 하면 성장 소비율이 작동하지 않음 | **주간 획득 별의 30% 미만** | 옷 가격 재조정 · 신규 아이템 투입 |
| **일일 사용 시간** | 아동 과몰입 방지 (부모 신뢰) | **일 30분 상한 알림** | 상한 알림 강화 |
| **아이 화면 결제·광고 노출** | 퍼핀 실패 지점(E-09, E-10) 반복 금지 | **0건** | 즉시 차단 — 협상 대상 아님 |
| **미션 거절률** | 부모-아이 갈등 신호 (거절 잦으면 루프가 벌점제로 변질) | **20% 미만** | 거절 사유 템플릿 · 미션 난이도 가이드 제공 |

## 5. 지표 수집 — 이벤트 로그 매핑

> 모든 지표는 **아이 앱 19종 · 부모 앱 7종**의 이벤트 로그로 자동 수집됩니다. (IA 기준, `대상_행동` 명명 규칙)

| 지표 | 수집 이벤트 |
|---|---|
| 첫 성장 경험 도달률 | `avatar_create_complete` → `lesson_complete` → `quiz_answer` → `star_earn` → `item_unlock` 퍼널 |
| 학습 완주율 | `lesson_start` / `lesson_complete` → `quiz_start` / `quiz_answer` |
| 성장 소비율 | `star_earn`(분모) ÷ `item_unlock` · `item_equip`(분자) |
| 자발적 재방문율 | `app_open`(속성: 용돈 잔액) + `lesson_start` |
| 해설 스킵률 | `quiz_answer` 대비 `quiz_explain_view` 미발생 비율 |
| 성장 가시성 조회율 | `learning_status_view`, `learning_answer_check` |
| 가치 유지율 | `subscription_renew` / `churn` |
| 미션 거절률 | `mission_approve` / `mission_reject` |
| 정답률 밴드 | `quiz_answer`(속성: 정답 여부) |
