# 핀테크 리스크 체크리스트

> **관점** "성공적인 경험을 줬을 때 한 번 더 체크하는 것" — 서비스가 **잘 될수록 커지는 위험**까지 포함해 점검
> **표기** ✅ 설계에 이미 반영 · 🔲 추가 조치 필요
> **대상 사용자** 만 7~14세 아동 + 법정대리인 → 아동 대상 금융 서비스의 규제 강도를 기준으로 점검

## 6. 우선순위 요약

```
심각도 ↑
  R1 사행성 ── R4 아이 사진 ── R3 아동 동의        ← 발생 시 서비스 존립 위협 (설계로 원천 차단)
  R17 아이 화면 광고·결제 ── R2 선불업              ← 금융소비자 보호 최전선 (0건 기준)
  R12 부모 확신 실패 ── R8 보상 역효과              ← 수익모델·정체성 위협 (실험 E2·E3로 검증)
  R6 별 인플레 ── R7 소진 ── R9 갈등 ── R10 과몰입   ← 운영 밸런싱 (Guardrail 지표로 상시 감시)
  R13 퀴즈 오류 ── R14 아바타 이상 ── R11 박탈감     ← 프로세스로 예방 (검수·프리셋·무과금)
  R18~R20 인증·보안                                ← MVP 이후 구현 시점에 확정 필요
```
